# Experiment Summaries

Store durable experiment summaries in this directory using the template in `../experiment-template.md`.

Name files `YYYY-MM-DD-short-description.md`. Include valid negative and inconclusive results when they could prevent duplicated work or influence a future decision.

Do not place raw logs, large generated outputs, datasets, or model weights here.
