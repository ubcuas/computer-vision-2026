# Competition Documentation

This directory separates official competition sources from the team's interpretations and engineering plans.

## Contents

- `sources/`: preserved copies of official documents. Do not edit these files.
- `source-register.md`: provenance, version, integrity, and status of each source.
- `task-1.md`: concise Task 1 requirements and the current computer-vision decomposition.
- `ambiguities.md`: questions that require organizer clarification, team decisions, or experiments.

## Information hierarchy

When information conflicts, use this order:

1. The latest official competition document or written organizer clarification.
2. A reviewed team decision recorded in this repository.
3. Reproducible experimental evidence.
4. Working notes, interpretations, and AI-generated suggestions.

The Markdown summaries improve discoverability but do not replace the official sources. Recheck the source register before relying on a competition-critical statement.

When a new official document is released, preserve it as a new file, update the source register, review the summaries and ambiguities, and mark the superseded source without deleting it.
